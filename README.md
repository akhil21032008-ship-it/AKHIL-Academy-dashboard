# AKHIL Academy Dashboard

A responsive student academic dashboard for tracking coursework, attendance, academic progress, class schedules, and upcoming assignments.

## Run locally

Open `index.html` in any modern web browser. The site is a static, dependency-free frontend; Google Fonts are loaded when an internet connection is available.

## Features

- Responsive dashboard with GPA, attendance, course, and assignment summaries
- Academic performance chart and course progress indicators
- Today's class schedule and upcoming assignment checklist
- Working sidebar navigation, search, mobile menu, and notification feedback
